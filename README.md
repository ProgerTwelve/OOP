# Репозиторий для обучения объектно-ориентированному программированию


##           Пакет src

* Модуль class_category.py
В этом модуле реализован класс Category, который содержит информацию о категориях
(имя, описание, список продуктов в категории). Также в нем есть счетчик категорий и 
счетчик продуктов, которые являются атрибутами всего класса


* Модуль class_product.py
В нем реализован класс Product, который содержит такие атрибуты как имя продукта,
описание продукта, цена продукта и количество продукта в наличии



##         Пакет tests

* Модуль test_class_category.py
В нем проводится тестирование класса Category:
Проверяется инициализация объектов и правильный подсчет количества категорий и
продуктов

* Модуль test_class_product.py
В нем проводятся тесты класса Product:
Проверяется инициализация объектов
